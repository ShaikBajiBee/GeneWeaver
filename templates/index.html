🔌 Developer REST API

Integrate GeneWeaver into your scripts, pipelines, or Jupyter notebooks:

# 1. Single sequence analysis
curl -X POST http://127.0.0.1:5000/api/analyze \
  -H "Content-Type: application/json" \
  -d '{"sequence": "ATGGCCATTGTAATGGGCCGCTGAAAGGGTGCCCGATAG"}'

# 2. Pairwise sequence alignment & SNP detection
curl -X POST http://127.0.0.1:5000/api/compare \
  -H "Content-Type: application/json" \
  -d '{"reference": "ATGGCCATTGTA", "query": "ATGGCCATGGTA"}'
